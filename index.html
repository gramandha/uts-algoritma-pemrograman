Soal 1 — Variabel, Tipe Data, dan Operator (20 poin)

a. (6 poin) Jelaskan perbedaan tipe data int, float, dan char dalam bahasa C. Berikan masing-masing satu contoh deklarasi variabel yang benar beserta nilai awalnya.

b. (4 poin) Apa perbedaan antara operator = (assignment) dan operator == (equality)? Sertakan contoh penggunaan masing-masing.

c. (10 poin) Tuliskan hasil output program berikut secara tepat:

#include <stdio.h> int main() { int a = 5, b = 3; int c = a++ + ++b; printf("a = %d, b = %d, c = %d\n", a, b, c); return 0; }
Soal 2 — Percabangan If-Else / Switch (20 poin)

Sebuah program akan dibuat untuk menentukan huruf nilai akhir berdasarkan nilai numerik (0–100):

80 – 100A
70 – 79B
60 – 69C
50 – 59D
0 – 49E
< 0 atau > 100"Nilai tidak valid"

Sebelum menulis program, kerjakan secara berurutan:

  1. (8 poin) Gambarkan flowchart dengan simbol yang tepat (terminator, proses, input/output, keputusan)
  2. (12 poin) Baru kemudian buat program lengkap bahasa C sesuai flowchart tersebut

Ketentuan program:

  1. Nilai dibaca menggunakan scanf
  2. Gunakan if-else if (atau switch bila tepat)
  3. Output contoh: Huruf nilai: B
  4. Sertakan deklarasi variabel yang sesuai
Soal 3 — Perulangan For (20 poin)

Kerjakan dua kasus berikut dengan perulangan for:

  • Kasus (i) — Pola bintang: menampilkan pola segitiga siku-siku ke kanan bawah:
    * ** *** **** *****
  • Kasus (ii) — Jumlah deret: membaca n lalu menampilkan & menghitung S = 1 + 2 + 3 + ... + n (contoh n=5 → S = 15).

Untuk kedua kasus, kerjakan secara berurutan:

  1. (4 poin) Tuliskan algoritma — kasus (i) 2 poin, kasus (ii) 2 poin
  2. (4 poin) Gambarkan flowchart dengan simbol yang tepat — kasus (i) 2 poin, kasus (ii) 2 poin
  3. (12 poin) Baru kemudian buat program lengkap bahasa C — kasus (i) 6 poin, kasus (ii) 6 poin
Soal 4 — Perulangan While / Do-While (20 poin)

Program berikut menghitung jumlah semua digit (input 1234 → 10). Lengkapi bagian (1)–(4):

#include <stdio.h> int main() { int bilangan, jumlah = 0; printf("Masukkan bilangan positif: "); scanf("%d", &bilangan); do { jumlah = jumlah + (1); /* (1) */ bilangan = (2); /* (2) */ } while ((3)); /* (3) */ printf("Jumlah semua digit = %d\n", jumlah); /* Validasi input: minta ulang jika bilangan ganjil */ do { printf("Masukkan bilangan genap: "); scanf("%d", &bilangan); } while ((4)); /* (4) */ printf("Terima kasih, input %d diterima.\n", bilangan); return 0; }
  1. Isi (1) dan (2) agar digit terakumulasi
  2. Isi (3) agar loop berhenti saat semua digit habis
  3. Isi (4) agar loop diulang selama input masih ganjil
  4. Jelaskan perbedaan perilaku while dan do-while
Soal 5 — Terapan Percabangan + Perulangan (20 poin)

Akan dibuat program untuk menentukan apakah bilangan bulat positif input pengguna adalah bilangan prima atau bukan (prima: hanya habis dibagi 1 dan dirinya sendiri).

Sebelum menulis program, kerjakan secara berurutan:

  1. (8 poin) Gambarkan flowchart dengan simbol yang tepat (terminator, proses, input/output, keputusan)
  2. (12 poin) Baru kemudian buat program lengkap bahasa C sesuai flowchart tersebut

Ketentuan program:

  1. Baca bilangan dengan scanf
  2. Gunakan perulangan (for/while) mengecek pembagian dari 2 sampai batas yang tepat
  3. Tampilkan: %d adalah bilangan prima atau %d bukan bilangan prima
  4. Kasus khusus: bilangan < 2 dinyatakan bukan prima
  5. Sertakan preprocessor, deklarasi, dan main() yang lengkap

Contoh output:

Masukkan bilangan: 17 17 adalah bilangan prima Masukkan bilangan: 15 15 bukan bilangan prima
